개인정보처리방침

최종 수정일: 2025년 5월 18일 적용 버전: 1.0.0 이상

탭 아카이브(Tab Archive)는 사용자가 열고 있는 브라우저 탭을 사용자 본인의 기기 내에 저장하고 관리할 수 있도록 돕는 Whale 브라우저 확장 프로그램입니다.

본 확장앱은 개발자가 사용자의 어떠한 정보도 수집·전송·열람하지 않으며, 아래에 설명되는 모든 데이터는 사용자의 기기에서 사용자 자신에 의해 저장·관리됩니다. 본 방침은 그 처리 과정을 투명하게 안내하기 위해 작성되었습니다.

01

처리하는 정보

탭 아카이브가 사용자의 기기 내에 저장하는 정보는 다음과 같습니다.

항목 설명 저장 시점
url 탭의 URL 주소 탭 저장 시
title 탭의 페이지 제목 탭 저장 시
favIconUrl 탭의 파비콘 이미지 URL 탭 저장 시
세션 이름 · 태그 사용자가 직접 입력한 그룹 이름 및 태그 사용자 입력 시
만료 시각 (TTL) 사용자가 설정한 탭 그룹의 만료 날짜·시각 TTL 설정 시

민감 정보 안내

URL과 페이지 제목에는 메일함 주소, 검색어, 세션 식별자 등 민감한 정보가 포함될 수 있습니다. 모든 데이터는 사용자의 기기에만 저장되며 외부로 전송되지 않지만, 민감한 탭을 저장하실 때는 이 점을 인지하고 이용해 주시기 바랍니다.

02

저장 방식 및 외부 전송

  • 저장된 모든 정보는 chrome.storage.local API를 통해 사용자의 기기 내부에만 저장됩니다.
  • 외부 서버, 분석 도구, 광고 네트워크 등 어떠한 제3자에게도 전송되지 않습니다.
  • 인터넷 연결 없이도 모든 기능이 동작합니다.
  • 개발자는 사용자의 저장 데이터에 접근할 수 있는 수단을 갖고 있지 않습니다.

03

보유 및 이용 기간

  • 저장된 데이터는 사용자가 직접 삭제하거나 확장앱을 제거할 때까지 사용자의 기기에 보관됩니다.
  • TTL(만료 시각)이 설정된 그룹은 만료 이후에도 사용자가 직접 삭제하기 전까지 유지됩니다.
  • 확장앱을 제거하면 chrome.storage.local에 저장된 모든 데이터가 함께 삭제됩니다.

04

권한 사용 목적

확장앱이 요청하는 권한과 각 권한의 사용 목적은 다음과 같습니다.

권한사용 목적
tabs 현재 탭의 URL, 제목, 파비콘을 읽어 저장합니다.
storage 탭 그룹 데이터를 기기 내에 영구 저장합니다.
activeTab 현재 활성 탭 정보에 접근합니다.
notifications TTL 만료 하루 전 알림을 전송합니다.
alarms TTL 만료 여부를 주기적으로 확인합니다 (1시간 간격).

각 권한은 위 목적 외의 용도로 사용되지 않습니다.

05

사용자의 권리

사용자는 언제든지 저장된 데이터에 대해 다음 권리를 행사할 수 있습니다.

  • 1 열람 및 확인 — 탭 아카이브 랜딩 페이지에서 저장된 모든 탭 그룹을 언제든지 확인할 수 있습니다.
  • 2 삭제 — 개별 탭, 탭 그룹을 랜딩 페이지에서 직접 삭제할 수 있습니다. 확장앱 제거 시 모든 로컬 데이터가 함께 삭제됩니다.
  • 3 동의 철회 — 확장앱을 제거하면 저장된 모든 데이터가 삭제되며, 이후 어떠한 정보도 저장되지 않습니다.
  • 4 처리 정지 요청 — 개인정보 처리 정지 또는 기타 권리 행사를 원하실 경우 아래 연락처로 문의하실 수 있습니다.

06

아동의 개인정보 보호

본 확장앱은 만 14세 미만 아동을 대상으로 하지 않으며, 별도의 아동 개인정보를 수집하지 않습니다. 보호자께서는 아동의 확장앱 이용 여부를 직접 관리해 주시기 바랍니다.

08

방침 변경 고지

본 개인정보처리방침은 법령 변경 또는 서비스 변경에 따라 수정될 수 있습니다.

  • 변경 시 확장앱 업데이트 노트 또는 본 페이지를 통해 안내드립니다.
  • 변경된 방침은 게시 시점부터 효력이 발생합니다.
  • 중요한 변경 사항이 있을 경우 본 페이지 상단의 "최종 수정일"이 갱신됩니다.
